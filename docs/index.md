# Sales Demos Documentation

Talk tracks, run sheets, architecture guides, and design plans for the
[sales.demos](https://github.com/ericcames/sales.demos) automation platform.

## For pre-sales engineers

Pick a demo from the **Demos** tab above. Each one has:

- **Run sheet** — the page you hold while presenting (minute markers, exact
  commands, recovery moves)
- **Talk track** — the narrative you read once the week before
- **Architecture** — the moving parts, timing, and object inventory
- **Objections** — what the audience asks, answered honestly

## For builders

The **Design Plans** tab has the engineering plans behind each use case — the
research, the decisions, and the phase plan.
